# 통합 로그·기존 위젯 밝은 화면 개편

2026-11-02. 최신1·3·4·6·7 화면과 같은 하늘색·민트·라벤더·연노랑을 적용했다.

- 통합 로그: 환경별 파스텔 카드, 청록 탐색 헤더, 연민트 표 헤더와 행 강조, 밝은 오른쪽 상세 패널. 기존 기간/시간기준/호스트/사이트/IP/OS/수집기/페이지 필터, 상세/보호원문/실시간 갱신 유지. 페이지 기준 통계는 전체 수집량으로 표시하지 않는다.
- 기존 위젯: 밝은 제목/기간 툴바, 개인화 목록·라이브러리, 저장된 강조색에 맞춘 카드/차트와 파스텔 배경, 편집·대화상자 가독성 개선. 저장된 위젯 좌표/크기/색 설정·데이터/API는 변경하지 않는다. 어두운 테마 설정이 남아 있어도 이번 두 화면의 작업 영역은 밝은 팔레트를 사용하며 설정 자체를 덮어쓰지 않는다.
- 배포 호환: 기존 허용된 logs.css/dashboard-builder.css를 theme.css 뒤에서 로드한다. 정적 경로/권한 API 추가 없음.

관련 기존 DOM/계산/폼검사4파일 통과. 임시 Flask 상태와 합성 로그·운영지표를 사용하는 브라우저에서 필터/상세, 위젯 복사본 편집·저장·재조회·취소, 768/390px 가로넘침 및 밝은 팔레트 검증. 운영 데이터 검증이나 운영 키 이관의 증거는 아니다.

운영 배포·원격 반영은 수행하지 않았다. 향후 배포는 미완료 암호화 변경을 제외한 별도 배포본으로 준비하고 sudo 명령은 사용자가 터미널에서 실행한다. 현재 변경 파일은 prototype/logs.html, logs.css, dashboard.html, dashboard-builder.css이다.
