멀티클라우드·사건·장치 화면도 같은 밝은 색상으로 정리했다. 사건 집계는 현재 필터 전체 기준, 장치 추가 요약은 전체필터 수와 현재페이지 상태 건수를 구분한다. 장치 수신확인을 최근로그 정상이라고 바꾸지 않는다. 수집 키 발급/연장/종료 절차는 유지한다. 멀티클라우드 차트는 기존 API 응답을 시각화하며 AWS 수집 구성/규칙 활성화를 수행하지 않는다.
