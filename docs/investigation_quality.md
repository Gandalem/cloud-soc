# 조사 신뢰성·탐지 품질 후속 구현

대상: JEONGRIM-SEO의 a581bf70ef09537a8461d7220a21f4f11f3e7e80 기준 누적 변경. 서버 접속, 실제 Elasticsearch 조회, 배포, 기존 데이터 변경, 커밋·푸시는 수행하지 않았다. 패치에는 이전 증분 탐지·클라우드 규칙 구현도 포함된다.

## 구현

1. 근거 조회 시 정규화 문서의 현재 내용으로 탐지 당시 event_hash를 다시 계산한다. 일치, 내용 변경, 참조 불일치, 문서 만료/누락, 과거 해시 미기록을 구분한다. 전체 문서는 계산에만 사용하고 선택 메타데이터만 응답한다. 원본 내용은 탐지 당시 해시가 없어 무결성을 보증하지 않는다. 과거 해시를 새 값으로 덮어쓰지 않는다. 기본 25개, 최대 100개씩 모든 저장 근거를 조회하며 251번째 근거 접근도 합성 검증했다.
2. soc-detection-runs-v1에 규칙 버전·스냅샷·처리 구간·입력/일치/불일치/평가 불가/제외/경보 수를 저장한다. evaluated는 평가 종료, committed는 SQLite 처리 위치 저장 완료다. committed 전달 의도와 처리 위치를 한 트랜잭션으로 저장하고 ES 전송 실패는 다음 실행에서 재시도한다. 포털에서 전송 대기를 표시한다. soc-detection-exclusions-v1은 지연·필드 누락·시각 오류별 정확한 문서 참조를 create-only로 저장한다. 같은 이벤트·규칙 버전·제외 사유의 재시도는 중복되지 않는다. 재시도 실행별 집계는 개별 시도 수이며 전역 고유 이벤트 합계가 아니다. 원문 payload는 저장하지 않는다.
3. AUTH-SEQ-001: 동일 조직/호스트/계정/출발 IP에서 300초 내 SSH 인증 실패 5회 이상 뒤 성공을 탐지한다. 성공 이전의 실패만 포함하며 동일 시각은 순서를 확정하지 않는다. 성공 후 실패 창을 초기화한다. 배치 경계·재시작·조직/호스트/계정/IP 분리·시간 경계를 합성 검증했다. 침해 확정으로 해석하지 않는다.

## 사용과 적용 주의

오프라인 규칙 검사(서버 접속 없음):

```text
python -m cloud_soc.detection --include-cloud --include-sequence
```

순차 규칙은 --include-sequence로 명시적으로 선택한다. 기본 SSH 규칙은 유지된다. 실행·제외 이력 수집은 증분 실행 경로에 적용되며 과거 snapshot 재생 경로에는 적용하지 않는다. 포털 메뉴 '탐지 실행·제외 이력'에서 최근 24시간을 규칙별 조회한다. API는 최대 30일 범위·페이지당 최대 100개·고정 인덱스만 허용한다. 관리 인증을 사용하며 페이지 오류·부분 샤드 응답을 성공으로 처리하지 않는다.

운영 적용 시 processing.setup의 이력 인덱스/상태 매핑, detection.setup의 create_doc 권한, portal.status_setup의 읽기 권한을 함께 준비해야 한다. 이번에는 실제 준비 명령을 실행하지 않았다.

runtime 계약이 2로 변경되어 기존 SQLite 상태를 조용히 재사용하지 않는다. 규칙 프로필/버전 변경 역시 새 명시적 상태 파일이 필요하다. 기존 파일을 삭제하지 말고 백업한 뒤, 재평가 시작 시각과 중복 경보 정책을 결정해 새 상태로 전환해야 한다. 자동 기존 데이터 전환은 구현하지 않았다. 저장 근거가 만료되면 해시 일치 여부를 확인할 수 없다. 허용 지연을 넘는 이벤트는 자동 재평가하지 않고 제외 기록을 남긴다.

## 검증

관련 Python 회귀 158건 통과. 신규 근거 무결성 8건, 순차 탐지 7건, 실행/제외 품질 10건 포함. 화면 로직 시험 79건 통과: 근거 전체 페이지 접근·해시 안내, 이력 페이지 이동·고정 조회 범위·늦은 응답 차단·문자열 안전 표시 포함. 규칙 6개 오프라인 검사와 기준 커밋에 대한 누적 패치 적용 검사 통과.

전체 Python 최초 실행 407건 중 통과 391건, 생략 10건, 실패 3건, 오류 3건. 이번 변경으로 확장된 읽기 권한 목록의 시험 1건은 수정하고 관련 재검증을 통과했다. 나머지 수집기 정책 시험 오류 3건과 Windows 스크립트 실행 정책에 막힌 설치기 시험 실패 2건은 미해결이며 전체 통과를 주장하지 않는다. 실제 ES 매핑/권한·운영 로그·브라우저 렌더링·운영 배포는 미검증이다.
