# 후속 확장·중복 통합 기록 — 2026-10-12

사용자가 필요 없는 작업을 판단해 삭제해도 된다고 승인했다. 현재 목표는 위험 징후 수집·설명 가능한 경보·근거 조회·사건 저장의 실제 인수다. 아래 원문과 미완료 상태를 보존하고 활성 목록에서만 제외/분리했다. 제외를 완료로 계산하지 않으며 구현된 코드·센서·화면·기존 데이터는 삭제하지 않았다.

기준: main `49db381`. 실제 구현·배포·수신·시험 상태를 변경하는 기록이 아니다. 기존 보존/백업 P2-02 사용자 보류와 민감정보·권한·키/큐/체크포인트·시작점 보호는 유지한다. 재개 시 필요한 자원·소스·승인과 별도 완료 기준을 정한다.

기존 원문:

```text
- [ ] P0C-12 확인 필요(진단 완료·정책 유지): 실제 SYSTEM Discovery exit 1 조사에서 관리자 CurrentUser RemoteSigned와 SYSTEM 유효 정책 Restricted 차이를 확인. 다운로드 차단 표시 없음, 복구 후 Filebeat/기존 Discovery 비활성 및 pending/probe 잔존 없음 확인. 사용자가 정책 유지·진단만 진행을 선택하여 전역/프로세스 실행 정책 변경과 완화 옵션 구현·설치 재시도는 하지 않는다. 현재 정책 아래 SYSTEM PowerShell 스크립트 방식은 실행 불가이며 실제 복구/수신은 미완료.
```
