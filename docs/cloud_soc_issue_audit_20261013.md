최종 회귀/관측 후 실제 잔여만 확정한다. 기준: ISSUE-02 핵심 업무 → ISSUE-01 보호/독립복구 → Windows/AWS/웹 필드 → 선택규칙 → 운영계측/역할/수명주기. 단일실측의 지속SLA·추가역할/조직 실제 인수·전체ES복원을 완료로 표시하지 않는다.
