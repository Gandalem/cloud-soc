# 포트폴리오 자료

과거 시연 안내5개·스크린샷3개와 당시 결과 snapshot은 [portfolio-docs.zip](../archive/portfolio-docs.zip)에 원래 경로로 보존했다. 합성 시연과 운영 인수는 구분한다. 현재 사용법은 [선택 실습](../optional_integrations.md#합성-시연과-포트폴리오)을 따른다.

- coverage.svg: CI/coverage 도구가 생성하는 배지. 원래 위치를 유지한다.
- evaluation.json: tools/portfolio_eval.py의 기본 결과 파일. 도구/CI 계약을 유지한다.
- tools/capture_portfolio.cjs: 실행하면 images 폴더를 다시 만든다. 과거 이미지를 압축한 것이 새 화면 검증을 뜻하지 않는다.

ZIP 내부 MANIFEST.json에서 파일별 SHA256을 확인할 수 있다. 현재 소스/화면·운영 성능은 당시 포트폴리오 수치로 보장하지 않는다.
