# 홈과 개인 대시보드

현재 상태(2026-10-12 후속): 지정 VMware 포털에 실제 보호 배포했고 기존 admin 비밀번호의 세션 로그인/로그아웃·개인 설정 재로그인/포털 재시작·실수신 API/집계를 확인했다. 아래 로컬 단계의 “미배포” 설명은 앞선 시점 이력이다. 추가 조직/역할과 실제 위험 경보/사건 인수는 [현재 목록](work_tracker.md), 배포 결과는 [보고서](archive/validation/dashboard_deployment_20261012.md)를 따른다.

홈은 관제 요약(경보·수신 로그·미종결 사건), 수신/경보 추이, 최근 경보 심각도, 경보 목록, 진행 사건의 6개 위젯을 제공한다. 고객의 관제 시작점은 홈이며 별도 관제 현황 메뉴는 두지 않는다. 수집 상태·분석 진단·해석 범위 기술 위젯은 고객 화면에서 제외했다. 운영자의 기존 진단과 직접 `operations.html` 경로는 보존했다.

`내 대시보드` 편집에서 이름·표시 위젯·위로/아래로 순서·기본/전체 너비, 기간(1시간/24시간/7일)·밝은/어두운 테마를 저장한다. 취소는 마지막 저장 구성으로 돌아간다. 기본 구성은 저장 전 미리보기다. 개인 화면의 기간 변경은 편집을 열어 저장 필요를 표시한다. 테마는 공통 헤더 버튼으로 즉시 전환하고 페이지 이동/새로고침에서도 유지하며 편집 취소로 되돌리지 않는다. 구성 저장 시 현재 테마 값도 기존 필드에 함께 저장한다. 현재 계정당 한 구성이며 키보드·모바일로 조작할 수 있다.

포털 상태의 `dashboards.sqlite`에 계정별 행을 저장한다. 같은 상태 경로의 앱 재생성·재로그인 후 유지 인수를 검증했다. 보호 DB 백업/복원에 이 파일도 포함해야 한다. 브라우저 저장소에는 허용된 `light`/`dark` 화면 테마 값만 저장하며 로그·자격 증명·위젯 구성은 복제하지 않는다. 고정 위젯/크기·기간·테마·짧은 이름만 저장하며 ES 주소·쿼리·조직/역할·외부 자산을 선택할 수 없다.

`GET/POST /api/dashboard`의 소유자는 인증 주체이며 actor 등의 추가 입력을 거부한다. 동일 출처·JSON·X-Cloud-SOC·세션 CSRF 검사를 유지한다. 최신 revision만 저장하고 409에서는 편집을 보존하며 명시적 서버 구성 다시 불러오기를 제공한다. 저장 중 조작을 잠그고 실패를 성공으로 표시하지 않는다. 조회 세션 계정은 자기 설정만 저장하고 사건/키/원문 권한은 늘어나지 않는다. 기존 관제 접근 권한의 관리자·세션 분석/조회 계정을 지원한다. Basic 제한 로그 조회 계정의 접근 제한은 유지한다.

기존 조직별 관제·사건 조회를 사용하고 전역 상태가 제한된 계정에는 확인 불가를 유지한다. 경보 수는 공격 횟수, 정규화는 안전/탐지 성공, 수집 보고 수는 정상 호스트 수가 아니다. 누락/실패를 0으로 바꾸지 않는다. 심각도 도넛은 최근 표시 50건 기준이며 전체 분포가 아니다. 미측정 CPU/메모리·차단 수·외부 안전 등급을 만들지 않는다. 60초 갱신은 이전 요청 취소/화면 숨김 중단을 적용한다.

## 2026-10-12 고객 화면 정리

홈 경보는 8건을 먼저 보여주고 펼치면 최신 최대 50건을 조회한다. 정확한 근거는 경보의 ‘근거 보기’로, 전체 사건 업무는 ‘사건 조사’로 연결한다. 전체 경보 페이지 탐색은 현재 미지원이며 50건 제한을 표시한다. 미종결 사건 수는 목록의 25건 표본이 아니라 동일 권한의 열린 사건 쿼리 전체 집계이며 조회 기간과 별도다.

기존 `pipeline`/`processing` 위젯 설정은 저장소에서 읽고 취소할 수 있으며 조회로 자동 수정하지 않는다. 렌더링/편집에서는 숨기고 명시적 저장 때만 현재 선택을 반영한다. 옛 구성에 기술 위젯만 있다면 위젯 선택 안내를 제공하고 기본 구성으로 복구할 수 있다.

분석 중단·지연·미확인 경고는 위젯 선택과 무관하게 한 번 표시한다. 상세 진단 링크나 정상 반복 이력은 고객 메뉴에 넣지 않는다. 기존 역할별 직접 진단 권한은 확대하거나 축소하지 않았다. 이번 변경도 로컬 소스이며 실제 배포는 별도다.

후속 정리의 관련 Python 58/7 subtests·화면 123·Chrome 18개·링크/보존 결과는 [정리 검증](archive/validation/customer_cleanup_20261012.md)에 있다. 기존 검증 이력은 그대로 유지하며 새 UI 실제 배포는 남는다.

## 2026-10-12 전역 테마 후속

홈의 ‘화면’ 드롭다운을 제거하고 모든 업무 화면의 공통 헤더에서 현재 화면 이름 옆 버튼으로 다크/화이트 모드를 전환한다. 버튼은 전환할 모드를 표시하며 선택·hover·키보드 focus의 메뉴 대비를 함께 유지한다. 로그 필터/표/상세 패널, 사건 목록/상세/폼과 에이전트 화면도 공통 팔레트를 사용한다.

브라우저에는 `cloud-soc.theme`의 허용된 두 값만 저장한다. 명시적 전역 선택이 없을 때만 기존 개인 구성의 테마를 받아들이며 저장/취소·서버 응답이 현재 전역 선택을 덮지 않는다. 테마는 같은 브라우저의 전 화면 표시 설정이며 다른 브라우저 자동 동기화가 아니다. 저장이 차단된 브라우저에서도 현재 페이지 전환은 동작하지만 새로고침 후 유지에는 저장 허용이 필요하다. 역할·조직·API 쿼리·로그인 비밀 값을 저장하거나 권한을 늘리지 않는다.

지정 포털 실제 후속 반영·검증 결과는 [테마 보고서](archive/validation/theme_validation_20261012.md)에 있다. UI 127·합성 42/실제 18개의 검증과 단계별 제한을 구분한다.
