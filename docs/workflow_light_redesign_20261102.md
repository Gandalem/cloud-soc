# 멀티클라우드·사건·장치 밝은 화면 후속 개편

2026-11-02. 기존 하늘색·민트·라벤더·연노랑을 유지했다. 프런트엔드 변경이며 수집기/기관권한/장치 수명주기 API를 변경하지 않는다.

- 멀티클라우드: 공급자 카드 바로 조회·선택 표시, 감사 이벤트 메타데이터 상세 대화상자·닫기, 기존 시계열/작업/로그 표 유지. 동시 필터 조회의 이전 응답이 최신 화면을 덮어쓰지 않도록 요청 세대를 검증한다. API키나 원문 재조회 기능을 추가하지 않는다.
- 사건 조사: 미종결/미배정/전체 상태 빠른 조회, 기존 필터 유지, 우선순위·상태별 파스텔 배지. 조회 집계는 현재 적용 조건 기준이며 상세는 기존 workbench 연결이다.
- 장치 관리: 등록 장치·키 이력·기존 설치 영역 이동, 키 카드 격자와 밝은 상세/설치/연장 영역. 등록확인과 최근 로그 정상은 계속 구분한다. 발급·연장·종료 확인 흐름은 유지한다.

DOM검사 파일3개 통과(최신 응답 우선 회귀 포함). 합성 데이터 브라우저에서 감사 상세/필터/조회실패시 이전자료유지, 사건빠른조회/우선순위/상세링크, 장치상세/영역이동/모바일 overflow 검사 통과. 라이프사이클 쓰기0 확인. 미리보기의 숫자는 운영 관측이 아니다.

운영 배포·원격 커밋/푸시는 이번 작업에서 수행하지 않았다. 같은 작업폴더에 미완료 암호화/KMS/TPM 관련 변경이 있으므로 화면 변경만 반영할 때 일반 전체 배포 스크립트를 그대로 실행하지 않는다. 배포 요청 시 운영 코드 기준 별도 checkout/검토본에 이번 UI 파일만 포함하고 기존 세션 로그인·로그아웃 수정을 보존해 검증한다.
