## 변경

고객 메뉴는 보안 관제 4개(홈·내 대시보드·통합 로그·사건 조사)와 에이전트 3개다. 운영 직접 관제/수집/분석/과거 분석 경로·기록·서버 RBAC는 보존한다. 홈에서 최대 50건 경보를 펼치고 정확한 근거로 이동해 원래 홈/개인 화면으로 복귀한다. 사건 수는 열린 사건 쿼리 전체 집계이며 기간별 경보와 다르다.

기본 위젯은 6개이며 `pipeline`/`processing`은 고객 렌더링/편집에서 제외한다. 기존 설정의 조회·취소는 SQLite 행을 수정하지 않고 명시적 저장 때만 현재 선택을 반영한다. 기술 위젯만 있는 옛 구성도 기본 구성으로 복구할 수 있다. 분석 중단/지연·미확인 경고는 위젯 선택과 독립적으로 표시한다.

README를 현재 설치/사용/갱신 안내로 줄이고 문서 색인을 추가했다. 이전 설계·중복 안내 12개와 검증/개선 11개를 보관하며 전체 작업 이력·이전 README를 보존했다. 상대 링크만 보정했으며 개인 보고서와 포트폴리오 자료는 변경하지 않았다. 기존 상위 24개 체크 상태와 완료 11개, P2-02 보류를 유지하고 P5-05 고객 홈 기준 변경을 명시했다.
