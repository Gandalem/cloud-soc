### 실제 화면·보호 상태와 남은 인수

CA·주소 검증을 유지한 실제 HTTPS의 응답을 읽기 전용 루프백 중계로 실제 Chrome에서 확인했다. 9개 화면×1440/390px **18개** 검사는 처음 과거 이력 503을 발견했고, 보완 후 지연 상태와 최종 복구/권한 복원 후 경고 상태에서 각각 **JS 오류 0·HTTP 실패 0·페이지 넘침 없음**으로 통과했다. 실행당 최종 한 건·명시적 입력 0 접기, API의 고유 committed 실행 13건을 확인했다. 개발 PC의 CA 저장소 변경이나 인증서 검사 우회는 없다. 직접 사설 CA 브라우저 접속·사용자 역할별 실서버 로그인 인수를 대신하지 않는다. 실제 사건이 없어 작업대의 이번 실데이터 검사는 포함하지 않았고 앞선 합성 작업대 검증과 구분한다.

`customer-review-candidate-v2/after-verified-recovery`에 현재 DB 6개 온라인 일관 백업/integrity, 두 실행 앱 이미지·설정·키/CA를 보호 보관했다. 최초 전환 전 보호 자료의 키/CA/관리자 해시/조직 정책 파일 14개는 바이트 불변이다. 기존 패키지 12·키 이력 22·enrollment 15·원문 접근 감사 34건의 모든 기존 행을 보존했고 실제 사건은 0건이었다. Basic 인증의 시각/실패 제한 상태는 변경 가능한 운영 상태로 취급한다.
