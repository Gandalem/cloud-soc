웹 로그

표준 access와 ModSecurity 한 줄 JSON 형식을 수집합니다. IIS·임의 형식은 이 설정으로 수집하지 않습니다. 수집 시작은 이 요청을 만든 UTC 시각입니다.

수집 내용

일반 정상 요청은 기존 보안 수집 정책에 따라 선별합니다. 알 수 없는 로그를 단순히 정상으로 가정해 제외하지 않습니다. 웹 본문·쿠키·인증 헤더는 전송하지 않습니다.

장치

등록 시험 수신은 설치 경로의 최초 도착 기록입니다. 일반 로그와 분석 상태는 별도로 조회합니다.

다운로드진단 자료 받기

다운로드한 ZIP을 모두 푸세요. Windows는 Start.cmd를 실행하고, Linux는 sudo sh soc-agent install을 실행합니다. 등록 정보는 대상 장치에만 전달하세요.

중지·재개·삭제·재설치

Linux: sudo sh soc-agent 메뉴, Windows: Start.cmd 메뉴를 사용하세요. 완료된 장치를 신규 설치로 덮어쓰지 않습니다. 실패 설치와 기존 설치의 복구 안내는 상태 확인 후 따릅니다.

로컬 삭제와 서버 접근 차단은 별개입니다. 아래 작업은 서버의 수집 자격 증명을 차단하며 원격 프로그램이나 저장된 로그·경보를 삭제하지 않습니다.
