통합 로그

호스트 로그·네트워크 관측·AWS/OCI 감사 이벤트를 하나의 표에서 조회합니다.

수집된 기록과 해석 결과는 다릅니다.

실제 수신 인덱스의 메타데이터와 지원되는 보안 이벤트 해석을 표시합니다. 행위 해석 미지원은 수집 실패가 아닙니다. 이벤트 ID·공급자로 기록을 구분하며, 없는 IP·계정·결과를 추측하거나 안전 판정으로 표시하지 않습니다.

행위·결과는 지원 해석기가 있으면 그 근거를 사용하고, 없으면 원본 필드를 표시합니다. Windows SID는 이름으로 확인되지 않은 주체 ID입니다. IP 검색은 원본의 호스트·출발지·목적지 IP 필드 기준입니다. 민감정보 보호 정책 검증 전까지 메시지 본문·전체 원문·내보내기는 제한됩니다. 네트워크 기록은 흐름·DNS·TLS 메타데이터이며 원본 PCAP이 아닙니다.

보호된 원문 필드

허용된 저장 필드만 표시합니다. 본문·명령 인자·비밀·알 수 없는 필드는 제외하며 전체 원본의 복사본이 아닙니다. 조회 사유와 접근 결과를 기록합니다.
