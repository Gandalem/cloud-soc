수집 목표: Windows·Linux의 OS·보안·서비스·애플리케이션 로그. 전체 로그는 실제 생성되고 접근 권한과 수집 설정이 확인된 채널·파일·저널 범위입니다. 현재는 합성 데이터이며, 실제 수집기·파서·조회 API는 미연결입니다.

Windows · Linux 수집 대상 보기 설계 범위 · 실제 지원 완료 아님

Windows

이벤트 채널: Security, System, Application, PowerShell, Defender, Sysmon 및 추가 채널

서비스·파일: IIS, 방화벽, DNS, 작업 스케줄러, 응용 프로그램 및 사용자 지정 로그

Linux

OS·보안: 인증/SSH/sudo, syslog/messages, journald, 커널, auditd, cron, 방화벽

서비스·파일: 웹 서버, 데이터베이스, 컨테이너, 응용 프로그램 및 사용자 지정 로그

기록 설정·권한·서비스 설치 여부에 따라 수집 가능 범위가 달라집니다. 등록한 소스의 누락·권한 오류도 별도로 확인해야 하며, 파싱되지 않은 원문도 보존하는 방향입니다.
